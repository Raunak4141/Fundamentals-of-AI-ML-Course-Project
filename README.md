# Fundamentals-of-AI-ML-Course-Project
--> Expense Tracker & Predictor

--> What this project does

This is a simple Python project that helps you **track your daily expenses** and **predict future spending** using a basic machine learning model. It also shows your spending in a graph so you can understand your habits better.
---
-->Features
* Add and view daily expenses
* Visualize spending with a graph
* Predict future expenses using ML
---

-->Requirements
Install the required libraries:

```bash
pip install pandas matplotlib seaborn scikit-learn
```
---

-->How to run
1. Download or clone this repository
2. Open the project folder
3. Run the Python file:

```bash
python expense_tracker.py
```
-->Output

* A graph showing your expenses
* A predicted expense for a future date
* Model accuracy printed in the console
-->How it works (simple idea)

The program uses your past expenses and applies a **linear regression model** to estimate future spending.

-->Note

This is a beginner-friendly project, so predictions may not be very accurate. You can improve it by using more data or advanced models.
